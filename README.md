# Dancing Line

A rhythm-style path game made in GameMaker, inspired by the mobile game *Dancing Line*. I made this in high school.

The line moves forward on its own, and you press a key to turn it at each corner of the path. Turn at the wrong time or run into a wall and the level restarts. The level has a hand-built forest map with a lake, bridges, logs, and animals that move as you pass by.

## Controls

| Key | Action |
| --- | --- |
| Space | Start moving / turn at a corner |
| R | Restart |

## Tech

GameMaker (GML)

## Running it

1. Install [GameMaker](https://gamemaker.io/).
2. Open `Final - Dancing Line.yyp`.
3. Press **F5** to run.
